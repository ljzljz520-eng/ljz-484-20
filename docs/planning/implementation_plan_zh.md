# 实施计划 (Implementation Plan)

## 目标描述
将应用程序从“暗黑赛博朋克”风格转换为“简洁/温暖浅色”美学。同时，修复后端小说封面的断链问题。

## 关键变更

### 1. 全局样式 (`main.css`)
- **背景**: 将 `slate-900` 翻转为 `slate-50` 作为主背景。
- **文字**: 翻转文字颜色（浅色变深色）。
- **毛玻璃效果**: 调整 `.glass-panel`，使用白色半透明而非深色半透明。
- **阴影**: 为浅色模式优化柔和阴影。

### 2. 后端数据 (`DataRepository.java`)
- **图片修复**: 替换“只有我知道剧情的测试员”的封面 URL，使用稳定可靠的 Unsplash 图片。

### 3. 前端界面
- **首页 (Home.vue)**: 优化英雄区渐变文字，确保在浅色背景下的可视性。
- **详情页 (Detail.vue)**: 确保背景模糊层不会遮挡文字。
- **阅读页 (Read.vue)**: 维持“暖色纸张”风格，并保持与全局浅色主题的一致性。

## 验收计划
1. **视觉检查**: 验证首页、详情页和阅读页是否明亮、整洁且易于阅读。
2. **图片检查**: 确认所有小说封面均能正常加载。
3. **对比度检查**: 确保文字和按钮在浅色背景下具有足够的辨识度。
